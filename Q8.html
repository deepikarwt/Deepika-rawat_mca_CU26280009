Computer Science Glossary

Algorithm
A step-by-step procedure for solving a problem or performing a computation.
Variable
A named storage location in memory that holds a value which can change.
Compiler
A program that translates source code written in a high-level language into machine code.
Array
A data structure that stores a fixed-size sequential collection of elements of the same type.
